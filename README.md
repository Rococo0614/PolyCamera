# 变化反射条件下的工业标识偏振识读课题

**建立日期：** 2026-09-21
**方向更新：** 2026-11-02

## 0. 当前主线

当前课题不再从“偏振相机能做什么”或“透明/高反深度怎么补”开始，而从固定工位工业识读的真实失效出发：

> **面向变化反射条件工业标识可靠识读的单曝光偏振自适应表示方法研究**

一句话问题定义：

> 光泽表面、包装覆膜和目标姿态变化会移动反射高光，使固定光源、固定相机角度和固定偏振方向无法始终获得最适合识读的图像；本课题研究如何利用单次曝光同时获得的多方向偏振信息，在不机械旋转偏振片的情况下，自适应生成有利于字符识读的表示。

详细研究故事、假设、系统架构、对照实验和 PPT 叙事见：

- `12_industrial_reading_research_story.md`
- `13_industrial_reading_experiment_plan.md`

## 1. 从工业需求到研究问题

```text
产品追溯 / 自动分拣 / 出入口管理需要稳定读取工业标识
        ↓
光泽、覆膜、曲面与姿态变化造成局部过曝和字符对比度下降
        ↓
调光、调角度和固定偏振片是成熟方案，但固定配置不能覆盖持续变化的反射
        ↓
机械旋转、多曝光和多光源分时会增加结构、维护、错位风险和工位节拍
        ↓
单曝光 DoFP 同时采集 0°/45°/90°/135° 多方向信息
        ↓
按帧或按区域自适应生成识读友好的偏振表示
        ↓
提高跨材质、跨姿态和跨光照条件下的识读可靠性
```

研究对象是**变化反射下的识读可靠性**；偏振相机是实现单曝光、多方向、无运动部件采集的技术手段。

## 2. 主任务与扩展边界

### 主任务

> 可控工业喷码工位中的字符检测与完整字符串识读。

优先对象：

- 金属罐、金属板；
- 光泽塑料件或塑料瓶；
- 覆膜纸箱、标签、包装袋；
- 轻微曲面和褶皱表面。

### 外部验证

在主任务成立后，再选择一项：

- 二维码/一维码解码；或
- 物流出入口车辆号牌/车辆标识识读。

二维码和车牌不与工业喷码同时作为三个并列主课题，避免范围失控。

## 3. 当前核心研究问题

1. 是否存在“没有一个固定偏振方向在所有条件下始终最优”的稳定现象？
2. 单曝光四方向观测是否保留互补的字符笔画与反射信息？
3. 全局虚拟检偏角或局部融合能否优于训练集最佳固定方向？
4. 增益是否体现在 worst-group、误读率和低分位可靠性，而不只体现在平均图像质量？
5. 四方向均过曝、低照或低调制度时，系统能否回退或拒绝输出？
6. 单曝光方案的采集、推理延迟和机械复杂度是否满足固定工位要求？

## 4. 研究路径

```text
Phase 0  工业问题证明
         RGB/S0/四固定方向在多材质、多姿态、多光照下的识读失效统计
            ↓
Phase 1  偏振测量链
         RAW、暗场/平场、四方向响应、配准、Stokes 与质量图
            ↓
Phase 2  固定表示与全局自适应
         最佳固定方向、虚拟检偏角、帧级方向/权重选择
            ↓
Phase 3  局部自适应表示
         只在全局方法不足且实验支持时研究空间权重与质量门控
            ↓
Phase 4  跨条件验证
         leave-one-material / light / SKU / batch
            ↓
Phase 5  外部场景
         二维码或物流车辆标识二选一
```

进入复杂模型前，必须先证明固定方向确有稳定局限，并且四方向存在可用于识读的互补信息。

## 5. 主评价指标

### 识读结果

- 完整字符串准确率 `exact-read rate`；
- Character Error Rate / 字符准确率；
- 字符检测 recall / precision；
- 误读率、漏读率与拒绝率；
- 扩展任务的二维码解码成功率。

### 可靠性

- worst-group exact-read rate；
- 跨材质、姿态、光照分组结果；
- P5/P10 低分位性能；
- risk-coverage 与置信度校准；
- 连续运行失败 burst。

### 工程性

- 单次曝光；
- 采集与推理延迟、FPS、工位节拍；
- 标定重复性；
- BOM、运动部件数和维护复杂度。

PSNR、SSIM、局部对比度和高光面积只作为解释指标，不能代替识读准确率。

## 6. “低成本”的严谨表述

DoFP 相机本身未必比普通相机便宜。当前主张应写成：

> **通过单相机、单次曝光和无电机偏振切换，以较低附加机械复杂度实现反射条件自适应。**

只有在比较相机/光源/机构 BOM、曝光次数、节拍和维护成本后，才能进一步声称总成本优势。

## 7. 既有深度研究如何处理

2026-10 至 2026-11 完成的 HAMMER 7,207 帧审计、PPFT 复现与偏振—深度调研均保留，不删除也不伪装成新识读课题的直接实验结果。

它们当前的作用是：

- 证明偏振信息具有明显的场景和质量依赖性；
- 提供 Stokes、DoLP/AoLP、质量评估和受控消融代码基础；
- 提醒新课题必须做材料内部、跨条件和可靠性评价；
- 作为已完成的技术储备或备选深度路线。

这些结果**不能直接证明偏振会提高工业字符识读率**。新主线必须重新采集识读数据并以字符串 ground truth 独立验证。

## 9. 当前决策原则

1. 先用识读准确率证明工业问题，再介绍偏振相机和模型。
2. 先比较 RGB、S0、四固定方向和最佳固定方向，再做自适应融合。
3. 主任务只选工业喷码；二维码或车牌只做一个外部验证。
4. 第一阶段固定成熟 OCR，避免把更大识读网络误认为偏振收益。
5. 报告跨材质/光照的最差组和拒绝策略，不只报告平均准确率。
6. DoFP 四子像素并非四张完整分辨率图，必须完成响应、空间和去马赛克误差标定。
7. 如果一个固定方向已在所有条件下足够稳定，应停止复杂自适应方法。
8. 不在没有 BOM、延迟和维护对照时笼统宣称“低成本”。
