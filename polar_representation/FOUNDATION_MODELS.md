# 通用预训练模型在偏振视觉中的能力、边界与选型

**调研日期：2026-11-11。**

**状态：文献与官方模型资料审计，不是本项目新训练/推理结果。** 本轮重点核验论文正文、具体表格和官方代码入口；预印本与仅摘要可见的论文分别标明。公开检查点的存在不等于已在本机下载或复现。

## 1. 结论与对当前方案的修正

1. **通用视觉先验已经很强，偏振的价值必须相对于强 RGB/S₀ 基线证明。** 同一偏振数据集上，RGB 模型已经能完成较好的语义分割、几何估计和图像恢复。
2. **已有直接证据支持“通用预训练 + 偏振适配”。** PPFT、ShareCMP，以及 2026 年的 DINOv3-SfP、通用恢复先验迁移和 PolarVLM 已覆盖多种适配路径。
3. **“通用模型做不到偏振”过于笼统。** 应区分：原生接口不支持、适配后尚有误差、跨任务证据缺失，以及观测本身不可辨识。前三者是工程/实证问题，最后一类不能仅靠增加参数解决。
4. **此前“一开始排除 DINO”建议过于保守。** DINOv3 官方有 ViT-S/16（21M）与 ConvNeXt-Tiny（29M）；2026 年已出现冻结 DINOv3 + 偏振分支的直接实测。推荐小模型进入强基线，避免一开始训练大模型。
5. **当前 PPT 的“归一化 Stokes + 预训练主干 + 多分支 + 门控”不能单独当作创新。** 2026 年已有高度相近工作。候选研究贡献应落实到：物理约束相对普通适配的独立增量、质量可验证的偏振利用，以及源任务训练后同一冻结表示的跨任务收益。

建议首轮选型：**MiT-B0 工程基线 + DINOv3 ConvNeXt-Tiny 强预训练基线**；另以 **InstructIR/NAFNet** 代表恢复先验，以 **PolarFree/WindowSeat** 代表反光恢复竞争方法。先完成 Gate A0，再逐项运行，而非同时铺开所有模型。

## 2. “见过偏振图”与“学过偏振测量”不是一回事

需要区分四种来源：

- 普通相机带偏振片拍出的单幅照片，进入网络时仍通常只是 RGB；
- 偏振相机导出的 S₀/RGB，已经压缩掉方向差分；
- AoLP/DoLP 伪彩图截图，未必保存原始量纲、角度零点和色标；
- 同曝光四方向、标定参数、线性响应、噪声/饱和信息齐全的偏振测量。

前三类可能出现在网络图像预训练语料中，但不能据此认定模型接受过第四类监督。DINOv3 的 LVD-1689M 等语料没有在本次核验材料中提供可审计的偏振样本比例；因此既不宣称“完全没见过”，也不宣称“已经懂偏振”。公开偏振基准与大规模预训练语料是否重叠同样需记录为未知。

本报告还区分三个能力层级：

| 层级 | 实验定义 | 可回答的问题 |
|---|---|---|
| 原检查点直接推理 | 已有完整任务模型，不在目标数据上更新 | 现成方案能否满足要求；跨数据集推理能力如何 |
| 冻结特征 + 新任务头 | 编码器冻结，在目标训练集拟合一个小头 | 通用表示已经包含多少任务可读信息；这不是完整零样本 |
| 偏振适配/微调 | 新增 adapter、融合或物理约束，并在偏振数据上训练 | 新测量能否在相同预训练起点上带来额外收益 |

只有某项任务适配完成，不等于得到通用偏振编码器；同一架构在三个数据集分别重训，也不等于同一权重冻结迁移。

## 3. 现有证据：已经到了什么程度

以下数值均限定在各自论文协议内，**不同论文/数据集之间的绝对分数不能直接排榜，也不能直接作为本项目目标值**。

### 3.1 水下/道路分割：RGB 已强，偏振适配仍有增量

**ShareCMP，TCSVT 2025，正文 Tables 2–3、§4.2.10 [S3]。** 使用 ImageNet-1K 初始化的 MiT/SegFormer 系列，增加四方向 PGA 和偏振辅助监督。

| 论文内方法 | UPLight mIoU ↑ | ZJU RGB-P mIoU ↑ |
|---|---:|---:|
| RGB SegFormer-B2 | 89.60% | 89.60% |
| RGB-P CMX，MiT-B2，DoLP 输入 | 92.07% | 92.20% |
| ShareCMP，MiT-B2，四方向输入 | 92.45% | 92.40% |

含义：

- 普通 RGB 预训练模型经任务训练已经解决了很大一部分语义识别；偏振价值是困难区域上的额外证据，不是从“完全不能识别”到“能识别”。
- ShareCMP 相对 RGB 表中的差值为 +2.85/+2.80 pp；相对强 RGB-P 基线差值更小。不同网络结构也有影响，不能把跨方法差值全部归因于偏振。
- 这些是各任务训练结果，不是 PolaRGB → 冻结 E → 分割的迁移结果；“共享”在该架构中主要指模态分支参数共享。
- UPLight 是水池中的 12 类对象，官方 1,441/350 为 train/validation；ZJU 的 344/50 也是 train/validation。它们不是所有水下/驾驶条件的覆盖保证。

### 3.2 深度增强：简单拼通道不如跨模态适配

**PPFT，CVPR 2024，Tables 1、3–6 [S4]。** 底座是 NYUv2 预训练的 **CompletionFormer**，不是 DINO 或 Depth Anything。

| 论文 Table 1，HAMMER 全传感器平均 | RMSE ↓（mm） |
|---|---:|
| Without polarization | 43.64 |
| Naive with polarization | 41.17 |
| PPFT with polarization | 28.63 |

Table 3 在 PPFT 架构内比较 RGB 与偏振 guidance，RMSE 为 **33.06 → 28.63 mm**。这个同结构对比比“跨模型下降多少”更有偏振归因价值。

- 说明可复用 RGB-D 先验，但增加通道不等于有效利用新模态。
- PPFT 还将适配策略用于 iDisc 法向估计；它复用的是方法设计，并非同一已训练编码器无更新跨任务迁移。
- 本项目已复现官方 test 的最终 PPFT 检查点：946 帧、2,838 条 sensor-frame，All mean RMSE **28.63444 mm**，见 `../depth_research/README.md`。这里不将论文消融表冒充本地已重训结果。
- HAMMER 的三种传感器共同训练再分别测试，不等于未见传感器泛化。

### 3.3 法向估计：2026 年已有 DINOv3 + 偏振的直接证据

**Revisiting Shape from Polarization in the Era of Vision Foundation Models，arXiv:2603.04817v1，2026-03-05；预印本，Table 2 [S2]。**

方法为可训练 UNet + 冻结 DINOv3 ConvNeXt-Base；DINO 只读 RGB/S₀，偏振信息在 UNet 分支中建模，再做多尺度融合。使用 40K 合成场景训练，在三个真实数据集评测。

| 方法/消融 | Table 2 报告的 Avg 法向角误差 ↓ |
|---|---:|
| RGB-only MoGe2 | 13.63° |
| 作者完整模型 | **12.54°** |
| 作者模型 w/o polarization | 18.43° |
| 作者模型 w/o DINO | 15.03° |
| 作者模型 w/o sensor-aware augmentation | 14.55° |

关键含义：

- **预训练、偏振和正确的噪声增强均有贡献。** 比较不应简化成“RGB 或偏振二选一”。
- 这里逐项引用论文的Avg列，没有重新假定等权聚合；其数值与三个展示子集数值的简单算术平均不完全一致，复现时仍需核对聚合权重。上述差值仅作为论文报告的证据，不当作本地已重算结果。
- MoGe2 在 SfPUEL 子集是 **10.88°**，优于作者模型 **12.76°**；完整模型赢的是三数据集均值，不是每个数据集都赢。
- 作者明确展示近无偏振物体和场景级背景几何的失败案例。AoLP 被噪声主导时，没有明显优于 RGB VFM。
- 40K 只是偏振任务训练规模，不包含 DINOv3 的大规模预训练成本；不能宣传为“总共只用了40K图片”。
- 本次作者主页的 `code & data` 链接为空，未确认可直接下载的该方法检查点；**DINOv3 底座本身有官方权重** [S1]。

### 3.4 去噪/去模糊/去马赛克：已开始直接迁移通用恢复先验

**Learning Polarization Image Restoration with General Restoration Priors，arXiv:2609.30728v1，2026-09-25；预印本 [S5]。**

这篇与当前提案直接相关：归一化 Stokes、强度/偏振分支、InstructIR 预训练、选择性门控、零初始化残差注入，以及复合退化 PolarCDD，均已有设计和消融。

论文 Appendix A.5 Table 7(b)，统一 100K 训练步的 PolarCDD 对比：

| InstructIR 适配方式 | 强度 PSNR ↑ | DoLP PSNR ↑ | AoP MAE ↓ |
|---|---:|---:|---:|
| 直接扩展至 9 通道 | 28.799 dB | 26.483 dB | 22.624° |
| 表中 InstructIR 通用适配基线 | 29.058 dB | 28.315 dB | 20.536° |
| 作者强度–偏振双分支适配 | **31.832 dB** | **29.932 dB** | **16.791°** |

正文 §4.2 说明一般模型比较包含“扩展通道”及“逐角 RGB 处理”两种适配并取较优者。表注对 3ch 的表述与实现细节仍需代码核查，不能把这一行解释为完全未经适配的零样本 InstructIR。

- Table 4 移除预训练先验后，AIO3 平均强度 PSNR **37.518 → 33.797 dB**，AoP MAE **13.009 → 13.909°**；是论文内实测，未在本项目复现。
- 论文跨任务恢复主要是**多退化联合训练**，不等于恢复源任务后冻结编码器迁移到语义分割。
- PolarCDD 含真实与合成来源，主要由 DoT 数据构造；blur/mosaic 部分为合成退化，不能当完整真实 DoFP 联合噪声真值。
- Appendix A.9 明确承认额外分支计算成本，以及大生成先验与轻量偏振支路联合训练的不稳定性。
- 本次未确认可用官方代码、权重和数据下载入口；先纳入直接竞争文献，不写“已复现”。

### 3.5 反光恢复：通用生成模型适配已是强竞争者

**WindowSeat，CVPR 2026 Workshops / arXiv:2512.05000v1 [S6]。** 将通用图像编辑 DiT 用 LoRA 适配为单图反光去除，公开版本使用 Qwen-Image-Edit-2509，一次前向生成 T。

- 公开版本在论文 Table 1 的 SIR²(500) 为 **28.60 dB / SSIM 0.937**；是该数据集的跨数据集测试，**不是 PolaRGB 结果**。
- 是经过反光任务适配的 RGB 模型，不是原始通用编辑模型直接达到的性能。
- 官方提供推理、评测脚本与权重，环境在 24 GB GPU 上验证。
- 能恢复可观察背景、利用生成先验填充细节；但不能用“看起来干净”证明恢复了唯一真实 T/R。论文还指出可能删除多阶反射，从而偏离 GT 或用户希望保留的内容。
- 适合作为 **RGB-only 恢复检查点对照**；不是当前小型共享编码器主干，也不因此启动大 diffusion 训练。

**PolarFree，CVPR 2025，Table 3 [S7]：** RGB-only 消融 **21.56 dB**，完整偏振模型 **22.44 dB**；LPIPS **0.1483 → 0.1325**。这是偏振源任务竞争方法，但它的条件 diffusion prior 是两阶段任务训练，不能将“使用 diffusion”自动写成“使用通用生成大模型预训练”。本地已核实论文 56/11 与 release 59/8 场景口径不同，因此不能把这些数字与本项目测试结果直接排榜。

### 3.6 语义推理与通用分割：已有扩展，但证据类型不同

| 工作 | 可核验能力 | 必须保留的边界 |
|---|---|---|
| **PolarVLM**，arXiv:2605.07574v1，2026-05，预印本 [S8] | LLaVA-1.5-13B + CLIP 偏振分支 + 两阶段适配；相同指令数据的 RGB baseline 到完整模型，Overall **4.85 → 6.08** | 是 GPT-4o-mini 的 **1–10 分评价**，不是正确率提高25.4个百分点；合成文本监督与评判依赖LLM，不是Stokes/几何真值误差，也不覆盖所有当前VLM |

### 3.7 水下恢复：已有“通用语义 + 偏振 + 恢复”组合，增益并非一律很大

**DORIS，arXiv:2610.17991v2，2026-11-10 更新；早期 v1 搜索结果名为 PolUR，预印本 [S10]。**

采用 CLIP-ViT/Vicuna-7B 的退化理解路径与 VAE/U-Net 恢复路径，将 RGB、偏振、退化语义结合；使用 MixPolar，室外子集无配对清晰真值。

- Table 5 同模型消融：移除偏振 **20.7018 dB / SSIM 0.742**，完整模型 **20.8262 dB / SSIM 0.735**。强度 PSNR 仅 **+0.1244 dB**，SSIM 反而下降；LPIPS略改善。
- Table 6 下游分割 IoU 为 **83.10 → 83.22%**，仅 +0.12 pp；这展示的是恢复图供下游使用，不是共享编码器冻结迁移。
- 相比大段“偏振很有效”的描述，同预算偏振消融更值得关注。当前不能预设偏振能在所有水质/光照下带来大增益。
- MixPolar 的配对恢复与室外无参考指标协议不同。UIQM/UCIQE/URanker 可以辅助观察，不能单独证明物理正确恢复；也不能把 UPLight 的分割标注当作水下清晰真值。

## 4. 通用模型仍缺什么：不是简单归咎于参数不够

### 4.1 信息论与可辨识边界

仅给 S₀ 时，可能有许多不同的 S₁、S₂ 对应相同强度；单 RGB 模型能利用先验**估计**偏振，却不能在所有场景保证唯一恢复真实偏振。

即使给四方向，理想线偏振观测也只提供三个独立 Stokes 量；T/R 各自有多个未知量，分解仍欠定。低DoLP、相似T/R结构、传输本身偏振和复杂玻璃会进一步扩大歧义。若全部有效观测都被遮挡/饱和抹去，生成模型只能给出先验估计，不能凭空提供确定的测量证据。

### 4.2 表示与测量接口不匹配

- RGB网络通常没有角度排列、零点、gain/offset、曝光与MPFA相位输入。
- 独立处理四方向的RGB恢复器可能改善各图PSNR，却改变 S₁/S₂ 的细小差分；这必须实测，不能假定始终破坏或始终保持。
- 普通RGB增强不会自动遵守Stokes旋转法则，逐角独立color jitter还可能直接破坏跨角物理关系。
- Q/U避免裸AoLP的角度跳变，但**S₀很小时归一化仍可能放大噪声**；仍需强度/SNR门控与有效域。

### 4.3 可感知质量不等于物理保真

- 反射被删除的同时，透射纹理、文字、玻璃边缘也可能被删。
- LPIPS或VLM美观评分改善不保证T/R分层正确。
- 重投影一致也不保证分层正确：`T=obs, R=0` 等退化解可以重组正确；需要任务真值、物理检查与失败分组共同约束。
- 用观测自己计算Stokes再渲染回观测，是解析自洽检查，不能独立证明学习的编码器有用。辅助重建必须经过待评价潜变量，不能让旁路绕过E。

### 4.4 迁移与质量仍是可检验问题

本次核验的上述工作中，尚未找到与本项目**完全相同**的完整证据链：PolaRGB源任务学习后，冻结包含adapter/质量门控在内的同一E，以小型头跨到水下/道路分割，同时执行S₀、重复、匹配噪声、打乱Q/U和物理损失消融。

这不等于证明无人做过或保证论文创新；但明确了下一轮文献和实验应追踪的缺口。

## 5. 应选择什么模型来优化

### 5.1 两个共享编码器候选，三个任务参照

| 模型 | 本项目角色与优先级 | 如何改造 | 主要代价/风险 |
|---|---|---|---|
| **MiT-B0，ImageNet-1K** [S14] | 第一轮轻量工程基线；多尺度输入/头接口较简单 | RGB/S₀沿用预训练；Q/U用小adapter；先只训练adapter/融合/头，再比较部分解冻 | 旧通用基线，不代表2026年最强视觉先验；仍需恢复头和高分辨率细节路径 |
| **DINOv3 ConvNeXt-Tiny，29M** [S1] | 首选强预训练共享编码器候选 | 初期冻结S₀分支，接轻量偏振残差与质量门控，保持四尺度输出；再按验证集比较部分微调 | 比MiT-B0重；29M仅底座不含支路/头。现有SfP证据是Base+UNet，Tiny方案是本项目拟验证而非已证实最优 |
| **DINOv3 ViT-S/16，21M；DINOv2 ViT-S/14备选** [S1,S17] | 如果要检验token型SSL表示，可替换上述DINO候选；不与Tiny同时铺开首轮完整网格 | 取patch tokens与中间层，配固定宽度readout；保留低层细节支路 | patch分辨率对小字符/细边缘不利；DINOv3权重入口需获取访问权限，本次HF raw model card请求为401；DINOv2有官方直接权重链接 |
| **InstructIR / NAFNet-width32** [S12,S13] | 恢复先验基线和可选恢复型底座；优先证明通用去噪/去模糊能做到多少 | 先用固定提示/固定检查点评价S₀或逐角恢复，再比较9通道与强度–偏振双流适配 | 原模型不是T/R分离器，必须任务适配后才算反光基线；恢复预训练不保证语义迁移，不能只比PSNR |
| **PolarFree** [S7] | 四方向反光任务专用参照 | 先核对release/checkpoint，再用冻结协议重算 | 不把官方56/11论文数直接与49/10/8结果混比；不是通用底座 |
| **WindowSeat，公开Qwen版** [S6] | 强RGB-only反光恢复参照；推理优先 | 固定已发布LoRA、提示、量化、tiling与输出尺寸，只读S₀/RGB | 24GB官方验证环境，计算预算远高于小型模型；只作不同预算性能参照，不启动大DiT训练 |

**首轮顺序：**MiT-B0验证接口与负对照 → 小型DINO验证强预训练下仍有偏振增量 → 选一个进入完整物理/质量消融与冻结迁移。InstructIR/NAFNet用于恢复参照，避免一开始把语义VFM、恢复网络与大生成模型全部融合。

**暂不作为主底座：**

- SAM类更适合独立分割参照或辅助标注，不天然提供反光恢复与偏振辐射表征。
- CLIP/SigLIP/VLM在开放词汇或物理问答任务明确后再选；当前没有语言监督主任务，没有必要先承担文本分支成本。PolarVLM说明适配可行，不代表LLM是当前T/R源任务的必要组成。
- FoundIR-v2 是CVPR2026通用恢复基础模型，有官方权重，依赖SDXL/CLIP/LLaVA等 [S15]；本次未见其原生偏振保真测试。可作为后续大预算参照，而非轻量Gate起点。

### 5.2 推荐改造方式及三个需要修正的架构细节

```text
四方向观测 + 实际可用标定/有效域
    ├─ S₀ → RGB-compatible transform → 预训练视觉主干
    ├─ Q,U → 小型偏振adapter/残差分支
    └─ 饱和、噪声估计、正交残差 → 小型质量预测器
                    ↓
          多尺度融合 + 小型源任务恢复头
                    ↓
          通过后冻结完整E → 分割小头
```

1. **避免三份完整大主干。** 优先一份通用强度主干 + 轻量偏振路径 + 极小质量路径；“三支路”不是三倍DINO。共享权重的具体位置需由验证集消融决定。
2. **物理通道与RGB预处理分开。** 物理损失在已冻结的测量域计算；RGB分支的标准化/动态范围适配不反写四方向测量。PolaRGB processed未经真实仪器标定时，不能假装拥有实测Â,b。
3. **加门控并不自动产生等变性。** 若zP为旋转协变向量，直接`zI+g(q)·zP`未必使任务输出不变。需要定义潜变量变换、等变模块或变换一致性训练，并实测重投影/任务一致性。先把它写成设计目标，不写成架构定理。

早期冻结底座、训练adapter/融合/头；验证集决定是否部分解冻。可以用小残差或零初始化输出投影保护初始RGB行为，同时检查偏振路径梯度，避免门控长期关闭。没有依据要求所有底座都严格采用同一学习率；应给相同调参预算。

## 6. 如何比较：必须拆开“预训练、输入、物理、质量、迁移”

### 6.1 能力基线与预算匹配基线

两类结果分别报告：

- **现成检查点能力表：**已有完整任务模型直接推理；预训练来源和总算力不同，报告任务质量、耗时、显存，不用来单独归因网络创新。
- **同底座机制表：**同一初始化、同数据、相同接口/容量和更新预算，只改变一个因素。跨MiT与DINO的差值不能单独称为偏振收益。

### 6.2 最小同底座实验矩阵

| 编号 | 输入 / 改动 | 回答什么 |
|---|---|---|
| B-S₀ | S₀，task loss | 该预训练底座在强度信息下的能力 |
| B-repeat | 重复S₀填充同容量接口，task loss | 更多通道/分支是否足够解释收益 |
| B-noise | 同S₀与训练侧冻结噪声副本，task loss | 非偏振扰动/正则化是否解释收益 |
| B-shuffle | 保留S₀，配对打乱Q/U，task loss | 当前样本对应关系是否必要 |
| B-pol | 正确S₀/Q/U，同结构，仅task loss | 偏振输入本身相对强度的增量 |
| B-phys | B-pol + 物理损失，保留相同辅助头结构 | **物理约束相对普通偏振适配**的增量 |
| B-full | B-phys +质量学习/门控；与相同参数的固定门控比较 | 质量信息和质量路由的增量 |

另外保留 Random-S₀ / Random-pol 两个同结构检查，以回答预训练初始化的收益；不是另建更小网络与预训练网络比较。

在每个任务自己的主指标上定义：

```text
Δinput = M(B-pol)  − M(B-S₀)
Δphys  = M(B-phys) − M(B-pol)
Δq     = M(B-full) − M(B-phys)
```

M 在同一比较中方向统一；不同任务分开报，不能把PSNR和mIoU相加。

**两个重要控制：**

- B-shuffle在同一split内配对打乱Q/U，尽量分层匹配S₀、噪声和质量；训练对照与测试时干预都做。仅测试时换入任意异域Q/U导致下降，可能只是分布外冲击，不足以完成物理归因。
- 由真实Q/U派生的DoLP/q_pol不能暗中喂给S₀-only对照。可以另设“S₀+质量信息”组，单独测量质量量本身的收益；对照破坏Q/U时，相关派生量也应一致处理并记录。

在B-phys确有收益之后，还应增加同辅助头/预算的普通重建或一致性正则对照，检验收益是否来自**物理特异约束**，而非任何额外监督或正则化。输入归因阶段先统一task loss；若某组额外获得Stokes/分层真值监督，应显式报告该监督差异。

### 6.3 每个主张对应的指标

| 评测对象 | 主指标 | 补充指标/必要条件 |
|---|---|---|
| PolaRGB透射恢复 | PSNR ↑（dB）、SSIM ↑、LPIPS ↓ | scene-macro为主要汇总，sample-micro并报；固定色彩/裁边/输出尺寸；clean preservation；弱反光、饱和、细纹理失败样本 |
| 偏振测量恢复 | S₁/S₂或Q/U误差、DoLP MAE ↓、AoLP圆周MAE ↓（°） | PDD或合成已知真值上评估；AoLP使用GT强度/DoLP/未饱和mask并报告覆盖率；不得由模型q选择自己的评分像素 |
| 物理一致性 | 预测Stokes重投影残差、变换一致性误差 | 单独比较已知真值误差；重建经过E；不能以复制观测或退化分层的低残差冒充恢复成功 |
| UPLight/ZJU分割 | mIoU ↑、逐类IoU | 报困难类别、边界F-score；固定ignored-label口径；冻结E与adapter，仅训练同容量头；10/25/100%标签曲线 |
| 噪声/曝光/MPFA稳健性 | 相对clean的性能下降曲线、风险–覆盖曲线 | 同底层场景配对corruption；匹配测试时推理次数；真实重复曝光与注入噪声分别报告 |
| 表示可读性 | 冻结E的线性/小头物理probe和任务probe | 同输入容量下与RGB、普通偏振适配比较；没有probe真值时只报告一致性，不伪造物理精度 |
| OCR（继续做时） | Exact ↑、CER ↓ | 按字符串长度分组；统计单位按文档/包装实例；单次部署输出，Oracle仅作诊断，不能GT选噪声或角度 |
| 深度/法向（历史扩展） | RMSE/MAE（mm或m）、AbsRel；法向角误差（°） | 深度coverage与真实sensor support；法向阈值准确率；不与反光PSNR混报 |
| 工程效率 | 总参数、可训练参数、GPU小时、端到端延迟p50/p95、峰值显存 | 固定硬件、分辨率、精度、batch、预热；四角独立推理、adapter和head开销全部计入 |

AoLP误差按180°轴周期计算：

```text
dφ = 0.5 · |atan2(sin(2(φ̂−φ)), cos(2(φ̂−φ)))|
```

mask阈值使用预先冻结的评测协议。比如当前PDD代理为GT DoLP>0.05；不能直接和[S5]可靠区域DoLP>0.1的结果混比。

### 6.4 怎样证明冻结迁移不是“预训练本来就很强”

每个下游至少比较：

1. 原始预训练E，冻结，只拟合下游头；
2. 同底座在PolaRGB以S₀训练后冻结；
3. 同底座在PolaRGB以正确偏振但不加物理约束训练后冻结；
4. 本项目完整物理/质量适配后冻结；
5. 同样处理过的repeat/noise/shuffle对照。

若4只优于随机初始化、不优于1或2，尚不能证明源任务偏振预训练有迁移价值；若4不优于3，不能声称物理约束帮助迁移。

“冻结E”包含adapter、融合、质量预测器及归一化运行状态；否则下游仍可能重新学习核心表示。任务头宽度、尺度、上采样与训练预算锁定；必要输入映射若可学习，其参数计入下游预算。源任务恢复与下游分割不要求完全相同头，但**同一任务内不同编码器的头必须匹配**。

### 6.5 划分、统计与判定

- PolaRGB按49/10/8场景，不按6,500图随机划分；同场景GT共享。
- 预处理、模型选择、提示、阈值和超参数只看训练/验证。release test已用于历史诊断，因此应诚实说明并尽可能加入新的场景/设备外测，而不是称其从未看过。
- UPLight/ZJU官方只有train/validation时，从train内部再划开发验证，保留官方validation作最终报告；按可用场景/序列身份去泄漏，身份缺失则记录限制。
- 至少3个seed报告均值/标准差；配对bootstrap按场景/文档/序列，而非像素或连续帧。seed波动与场景抽样不确定性分开报。
- 主比较在看test前固定；若主张同时优于多个对照，报告各配对差值和多重比较处理，不在test上挑最弱基线或最有利指标。
- 通过标准同时要求**统计正增量、最终测试前确定的实际收益阈值、clean损伤受控与可接受预算**。本报告不凭空指定普适的+0.5dB/+1mIoU门槛；这些须根据验证集波动和实际成本预注册。

## 7. 最小执行建议

1. 完成既定Gate A0与至少一个下游的数据接口审计；本轮调研不改变训练启动条件。
2. 在MiT-B0与小型DINO上先跑冻结S₀特征+小头，确认现成通用表示的强度基线。
3. 用相同接口完成B-pol vs B-S₀；通过后扩展repeat/noise/shuffle。
4. 单独比较B-phys vs B-pol、B-full vs B-phys。优先回答“物理和质量各自有没有用”，不先堆所有损失。
5. 冻结候选完整E，在一个下游执行上述四个阶段的表示比较和标签效率曲线，再考虑第二个下游。
6. 对照PolarFree和WindowSeat的端到端任务质量；它们是不同输入/预算的竞争参照，不能用其参数差异来解释小模型内部归因。

**最终值得证明的主张：在强通用预训练先验已经存在的条件下，经过测量与质量约束的偏振适配，是否能用可控成本提供稳定、可归因、可冻结迁移的额外信息。**
